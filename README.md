# Pomodoro Timer

A simple Pomodoro timer built with HTML, CSS, and JavaScript—just for fun! 🎯   
Designed as a lightweight widget for Notion, so you can stay focused without leaving your workspace.

## Features
- Focus, Short Break, and Long Break modes
- Customizable duration for each mode
- Theme customization (background & font color)
- Popup notification when timer ends
- Fully responsive and mobile-friendly
- No installation needed, just open in your browser
